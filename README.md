# 🌉 Puentes

> Turn a few vacation days into many days off: finds the best 'bridges' around Spanish public holidays and tells you exactly which days to request.

**Free · open source · 100% in your browser (nothing is uploaded).**

<sub>[🇪🇸 Español abajo](#-español)</sub>

## Features
- Greedy optimiser by days-off per vacation day
- custom regional holidays

## Use
Open `index.html` — no install, no server, no build. Host it free on GitHub Pages.

## Basis
Festivos nacionales de España (Viernes Santo calculado).

## ⚠️ Disclaimer
Orientative tool — not legal, tax or financial advice. Check your specific case with a professional.
